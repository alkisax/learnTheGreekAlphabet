Μου άρεσε πολύ η απλή ιδέα του: μια μικρή εφαρμογή που δεν προσπαθεί να σου μάθει ολόκληρη τη γλώσσα, αλλά σου δίνει έναν εύκολο τρόπο να γνωρίσεις το αλφάβητο και να αρχίσεις να διαβάζεις.

Έτσι αποφάσισα να φτιάξω κάτι αντίστοιχο για τα ελληνικά. 🇬🇷

Το **Learn the Greek Alphabet** απευθύνεται κυρίως σε τουρίστες, ταξιδιώτες και ανθρώπους που δεν γνωρίζουν ελληνικά αλλά θα ήθελαν να μπορούν να αναγνωρίζουν τα γράμματα και να διαβάζουν μερικές βασικές λέξεις και πινακίδες.

Η εφαρμογή περιλαμβάνει 17 μικρά μαθήματα που ξεκινούν από τα βασικά γράμματα και προχωρούν σταδιακά σε:

- προφορά στα Νέα Ελληνικά
- συνδυασμούς φωνηέντων
- συνδυασμούς συμφώνων
- τόνο και προφορά
- μικρές ασκήσεις ανάγνωσης λέξεων

Στις ασκήσεις ο χρήστης προσπαθεί να γράψει με λατινικούς χαρακτήρες πώς προφέρεται μια ελληνική λέξη και παίρνει άμεσα feedback.

Έφτιαξα δύο ξεχωριστές εκδόσεις:

🌐 React / Vite / TypeScript για web  
📱 React Native / Expo για Android

Δεν υπάρχει backend, database ή login — όλη η εκπαιδευτική λειτουργία γίνεται τοπικά στην εφαρμογή.

Τεχνολογικά ήταν επίσης μια ευκαιρία να δουλέψω περισσότερο με:

- React Native & Expo Router
- reusable lesson/exercise components
- mobile safe areas και scrolling layouts
- AdMob banners και interstitial ads
- Android signing και AAB release builds
- Google Play closed testing και production deployment
- React Router, Tailwind CSS και web deployment με Nginx / Hetzner

Και το σημαντικότερο για μένα: η εφαρμογή ολοκλήρωσε πλέον όλο το Google Play deployment/testing cycle και είναι διαθέσιμη κανονικά στο Google Play 🎉

### 🇬🇷 Learn the Greek Alphabet — Web & Android Learning App

A small educational app aimed mainly at tourists and complete beginners who want to recognize the Greek alphabet and start reading simple Greek words. It includes 17 progressive lessons with Modern Greek pronunciation, letter combinations and interactive reading exercises. Built as separate React/Vite web and React Native/Expo Android applications, with the Android version published on Google Play.

- 🌐 **Live Web App:** [Learn the Greek Alphabet](https://learngreekalphabet.gr/)
- 📱 **Google Play:** [Learn the Greek Alphabet](https://play.google.com/store/apps/details?id=com.alkisax.learngreekalphabet)
